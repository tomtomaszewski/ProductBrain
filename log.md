# Log

Historia pracy z vaultem. Najnowsze wpisy na dole.

## Format wpisu

`YYYY-MM-DD - setup - tryb, data startu, język, zmiany w tematach`
`YYYY-MM-DD - review - nazwa-pliku -> archiwum/... - które tematy zaktualizowane, ile pytań zamkniętych`
`YYYY-MM-DD - reject - nazwa-pliku - dlaczego odrzucony`
`YYYY-MM-DD - gaps - top luki w jednym zdaniu`
`YYYY-MM-DD - kontekst - wariant (Mini / Standard / Pełny), ścieżka, które tematy`
